# Splitzy

Splitzy is a responsive bill-splitting web application that helps users manage shared expenses and settle group bills efficiently. The application automates expense calculations, tracks individual contributions, and determines the most equitable way to settle balances with minimal transactions.

## Live Demo

**Live Website:** https://splitzyy.netlify.app/

## Features

* Automated bill splitting among multiple participants
* Individual expense assignment for accurate cost tracking
* Smart settlement algorithm to minimize the number of transactions
* Real-time balance calculations
* Responsive design for seamless use across devices
* Simple and intuitive user interface
* Google Analytics integration for user engagement tracking
* Fast and reliable deployment with Netlify

## How It Works

1. Add participants involved in the expense.
2. Enter expense details and specify who paid.
3. Assign expenses to one or multiple participants.
4. Splitzy automatically calculates individual balances.
5. The settlement algorithm determines the most efficient payment flow.
6. View a clear settlement summary showing who owes whom.

## Algorithm Overview

Splitzy uses a custom settlement algorithm to simplify debt resolution by:

* Calculating the net balance of every participant
* Identifying creditors (people who should receive money)
* Identifying debtors (people who owe money)
* Matching creditors and debtors to minimize transactions
* Generating an optimized settlement summary

This ensures fair and efficient bill settlement for all group members.
